## 1. 要旨

- 30ステップ生成のうち特定ステップを飛ばしたときの画質劣化（以下「損傷」＝スキップあり画像と基準画像の見た目の差を LPIPS で数値化したもの）を、固定バージョンの Forge neo で総計 3,186 枚（基準画像45枚を含む）生成して測り直した。
- 損傷は生成の序盤に集中し（Spearman ρ=−0.784）、ピークは最序盤ではなく skip2〜4 付近にある。位置が損傷量の支配的な決定要因である（η²=0.667）。
- 複数ステップを飛ばしたときの損傷は、**各ステップ単独の損傷の和に頭打ち補正（飽和リンク）を掛けるだけ**でよく説明できる。連続スキップのペナルティ項は不要であることが、事前登録した基準に対する out-of-sample 検証（450枚）で確定した（順位相関 ρ=0.930、streak 項を足すと逆に ρ が 0.049 悪化）。
- 一方、「損傷は軌道座標 z だけで決まる」という HareSkip の中心仮説は素直には成立しなかった。Shift を 3 から 1 に変えると損傷カーブの形（急峻さ）自体が変わる。
- 予測式の順位精度は実用水準に達したが、絶対値には一貫した安全側（実測 ≦ 予測）のバイアスが残る。次の有望なレバーは予測式の精緻化ではなく ResRefine 後処理の改良である。

**LPIPS の目安（本レポート共通のスケール感）**: 0.02 ≈ 並べて見比べても見分けが困難、0.1〜0.2 ≈ 細部の塗りが明らかに違う、0.3 ≈ 構図が変わる水準、0.5 ≈ 実質別画像。

## 2. 背景と目的

### 2.1 現行パラメータの出自の問題

HareSkip は、拡散モデルのサンプリング軌道上の座標 z（`LogSnrProxy` = 2·ln((1−t)/t)、生成が進むほど大きくなる）に沿って「そのステップを飛ばしてよい確率」を滑らかに変化させる拡張である。現行の確率勾配 `sigmoid_band_v0.1` は次の形をとる（出典: `docs/HareSkip-design.md`、`EXPERIMENT-PLAN.md` §1）:

```text
p_skip(z; a) = p_cap(a) · sigmoid((z − z_enter(a)) / tau_enter(a)) · sigmoid((z_exit(a) − z) / tau_exit)
```

このパラメータは UjiCache（旧 TeaCache 系）時代に集めたデータから導かれたものだが、そのデータには**選択バイアス**があった。すなわち「うまくいったパターンの skip 分布」を観察して逆算した経験則であり、「各位置を飛ばすと実際どれだけ壊れるか」を系統的に測ったものではない。特に立ち下がり側（taper: `z_exit` / `tau_exit`）は現行データでは較正を正当化できない。立ち上がり側（序盤が危険）だけはバイアスに依存しない証拠で支持される。

そこで、位置ごとの損傷を全域で測り直し、確率勾配とゾーン境界を再較正することを目的とした。

### 2.2 バージョン交絡事件

第1段階の測定を終えて分析に入った 2026-07-17〜18、深刻な交絡が発覚した（`EXPERIMENT-LOG.md` 2026-07-17〜18 の各エントリ）。

候補画像（スキップあり）同士は互いに近いのに、基準画像（Reference、スキップなし）だけが系統的に遠い、という異常が見つかった。例: Euler-Beta の android 条件で、基準 vs 候補 skip30 の画素 RMSE が 28.3 なのに対し、候補 skip29 vs skip30 は 10.2。条件ごとに 0.025〜0.207 の「下駄」が全パターンに一律に乗っていた。

調査の結果、原因は HareSkip 拡張ではなく **Forge neo 本体のバージョン差**だった。同一のプロンプト・シード・サンプラー・設定でも、本体を更新すると出力が変わる。基準画像は 1ヶ月前の neo-2.24 で、候補は neo-2.26 で生成されていた。さらに git の操作履歴（reflog）を追ったところ、候補 1,305 枚自体が 3 つの異なるコミットにまたがって生成されており、特に Euler-Beta 系 15 条件だけが別コミット（高速化コミットを含む）で作られていた。「Euler-Beta だけ損傷の振幅が半分」という第1段階の所見は、サンプラーの性質とコミット差が切り分け不能な状態だった。

実機 API 検証で決着した（`EXPERIMENT-LOG.md` 2026-07-18 続き2）:

| 比較 | 画素 RMSE（1.6以下 ≈ 事実上同一） |
| --- | ---: |
| 新画像(2.27・拡張なし) vs 旧Reference(2.24・拡張なし) | 18.5 |
| 新画像(2.27・拡張なし) vs 候補skip30(2.26・拡張有効) | 14.1 |
| 新画像(2.27・拡張有効・スキップなし) vs 新画像(2.27・拡張なし) | **0.0（完全一致）** |

つまり **HareSkip 拡張は無実**（同一環境なら拡張の有無で出力はビット単位で一致する＝素通し性の実機証明）であり、**乖離は本体バージョン差で確定**した。

### 2.3 再較正の実施方針

ユーザー裁定により、Forge neo 本体をコミット `b61642140acb7c2f1c65c5d0f2ab961b7366c02e`（以下 `b6164214`）に固定し、キャンペーン完走まで更新を凍結。基準 45 枚と候補 1,305 枚を全面再生成した。旧データ（`Reference-images/`、`Calibration-phase1/`）は無効データの監査証跡として凍結し、変更・削除しない。以降の全生成物は同一コミット製であることを、PNG メタデータの Version 単一値（neo-2.27 表記）で毎回検算している。

再生成後、下駄は解消した。条件別の LPIPS-VGG 最小値は旧 0.09〜0.21 → 新 0.006〜0.044、全体中央値は 0.125 → 0.045 まで下がり、「ほぼスキップなしの画像は基準とほぼ同一」という理論どおりの姿になった（`analysis-phase1-02/REPORT.md` §11.1）。

## 3. 方法

### 3.1 3段階構造

パターンから品質への全写像を測ることは原理的に不可能である（30ステップ中15ステップを選ぶ組み合わせは C(30,15) ≈ 1.55億通り）。そこで方針を転換し、**「調整項を数個しか持たない計算式で全域を予測できるか」を測る**設計とした。予測が当たれば、「全部を試さなかったこと」自体が正当化される。

> **用語注**: この計算式を「低次元モデル」とは呼ばない（生成AI の文脈では次元削減した重みテンソルを連想させるため。2026-07-27 ユーザー裁定）。本レポートでは**「予測式」**（調整項を削減した計算式）と呼ぶ。実体はニューラルネットとは無関係の、単発損傷の実測値を入力とする数式である。
>
> **用語注**: 実験の段構造は「第N層」ではなく**「第N段階」**と呼ぶ（"層" はニューラルネットの layer と紛らわしいため。2026-07-21 ユーザー裁定）。

| 段階 | 内容 | 生成数 |
| --- | --- | ---: |
| 第1段階 | 単発スキップ掃引（1ステップだけ飛ばす、step 2〜30 の 29 位置） | 29 × 45 = **1,305** |
| 第2段階 | 相互作用の抽出（隣接ペア・距離スキャン・帯域間ペア・チェーン・三点、28パターン） | 28 × 45 = **1,260** |
| 第3段階 | HareSkip 実運用パターンでの out-of-sample 検証（10パターン） | 10 × 45 = **450** |
| ±1ステップアンカー | 拡張なしで総ステップ数のみ 29/31 に変えた画像 | 45 × 2 = **90** |
| Shift スポットチェック | Shift=1 での 5 測定点 | 6条件 × 5 + 基準6 = **36** |

step 1 が除外されているのは、Manual Skip が step 1 の指定を検証エラーで拒否するためである（step 1 は residual が未保持で物理的にスキップ不可）。

### 3.2 条件マトリクス（45条件）

- **サンプラー系 3**: ER SDE-Beta / ER SDE-Simple / Euler-Beta
- **プロンプト 5**: schoolgirl（猫を抱える少女）/ android（森を歩くアンドロイド）/ woman（油絵の女性の肖像画）/ shop（店舗の風景画）/ inkwash（日本画の花）
- **シード 3**: 3000995193 / 2455776111 / 2767019676

全段階を通じて、Shift=3（Anima 既定値）、30 steps、CFG 4、1536×1536、ResRefine formula = `Reuse (residual only)` に固定した。ResRefine を Reuse に固定するのは、スキップ位置の純粋効果を測るためである（残差の加工方式が混ざると、位置の効果と加工の効果が切り分けられなくなる）。

### 3.3 Manual Skip モード

測定の実行手段は HareSkip の第3モード「Manual Skip」である。複数行テキストボックスに 1 行 = 1 パターン（カンマ区切りの 1 始まりステップ番号）を貼り付け、Generate を 1 回押すと行数分のジョブに自動展開される。全行は同一のシードテンプレートを共有するため、「同一シードでスキップ位置だけが違う」比較が成立する。確率モデルも Skip window（既定 0.05〜0.95 の保護区間）も素通しになる仕様であり、だからこそ最終ステップ付近の損傷まで実測できた。

各画像の infotext には `Manual skipped_steps`（**実現値**・1始まり）が書き込まれる。これは指定値ではなく patcher が実際に積んだスキップ記録から生成されるため真正であり、「その画像がどのパターンで生成されたか」を自己記述する。全キャンペーンの受け入れ検査はこの実現値とファイル名・パターン正典の三者照合で行った。

**既知の制約（2026-07-14 実機確認）**: Forge 本体は全スクリプトフックの例外を握り潰すため、不正入力を検出しても生成は止まらない。実挙動は「行展開もスキップも適用されず、スキップゼロの画像が 1 枚生成される」。この場合 infotext の `Manual skipped_steps` が欠落するため事後検出が可能であり、fail-stop 修正（`shared.state.interrupt()` の呼び出し）は「生成パイプライン深部に触るコストが利益を上回りうる」との判断で提案として凍結され、運用（枚数・infotext の検算）で対処している。

### 3.4 評価指標: Nz DoppelPix Judge

損傷の測定には Nz DoppelPix Judge（port 7870）を用い、**LPIPS-VGG を主指標**、SSIM 11p を副指標とした（CLIP / ImageReward は無効）。手順の正典は `experiment-HareSkip/NZ-DOPPELPIX-JUDGE.md`。

**致命閾値 θ の定義（2026-07-21 確定）**: θ は「実質同じ画像と見做す基準」では**ない**。ステップスキップは原理上必ず差分を生むため、同一性を主張することは欺瞞になる。θ は**「差異の量が実用上の問題を生まない合格基準」**である。この基準に客観的な物差しを与えるために ±1 ステップアンカー実験を導入した（§4.2）。

### 3.5 事前登録の規律

第3段階では、**実測を見る前に予測を凍結する**手続きを取った。

- 検証用パターン正典 `patterns/stage3-holdout-patterns.txt`（10行）を凍結: **SHA-256 `659A7445...7CD3`**（`EXPERIMENT-LOG.md` 2026-07-28）。HareSkip の確率モデル（`sigmoid_band_v0.1`）・Skip window・ゾーン別 max streak・skip_seed 導出をオフラインでシミュレートして実現パターンを列挙したもの。**拡張モジュールを直接 import して突合し**、params・z/p・skip ベクトル・skip_seed・乱数消費の短絡評価まで全一致を確認した（拡張テスト 42 件全緑）。
- 450 点の事前予測表 `analysis-stage3/stage3-predictions.csv` を凍結: **SHA-256 `F8495DD1...FA131D`**（`EXPERIMENT-LOG.md` 2026-07-28 続き）。予測式のパラメータは第2段階 1,260 点のみで較正し、第3段階データでの再調整は禁止した。
- 合格基準（§4.4）も測定前に固定した（`EXPERIMENT-PLAN.md` §11.3）。

生成後の受け入れ検査で、第3段階の manifest にこれら 2 つの SHA-256 が一致記録されていることを確認している。

## 4. 結果

### 4.1 第1段階: 損傷曲線の形（1,305枚）

正典: `experiment-HareSkip/analysis-phase1-02/REPORT.md`

| 観察 | 数値 | 出典 |
| --- | --- | --- |
| 序盤集中（位置と損傷の単調減少） | Spearman ρ = **−0.784** | REPORT.md §3 |
| 序盤(skip 2–10) vs 後半(11–30) の効果量 | Cliff's δ = **0.886**（large） | REPORT.md §3 |
| 中央値ピーク位置 | ERSDE-Beta = skip**4**（0.419）/ ERSDE-Simple = skip**2**（0.420）/ Euler-Beta = skip**3**（0.177） | REPORT.md §3 |
| 全体最大損傷 | **0.670**（shop-5193, skip4）＝ 別画像水準 | REPORT.md §3 |
| ばらつきの分解 | position η²=**0.667** ≫ prompt 0.115 ≫ sampler 0.007 ≈ seed 0.001 | REPORT.md §6 |
| 致命消失境界 | θ=q95(0.303) で **skip9 以降は全分位が閾値未満・超過ゼロ** | REPORT.md §7 |

**(1) 序盤集中は明瞭**。交絡を除いたことで効果量が旧データ（ρ=−0.375、δ=0.532）から大きく立ち上がった。注意すべきは**ピークが最序盤ではない**ことで、ER-SDE-Beta では skip4 が最悪である。skip1 から単調に減衰させる勾配設計だと、実ピークの直前で保護が緩くなり、最悪の位置を取り逃す恐れがある。

**(2) 振幅縮小説を支持**。後半で損傷のばらつきが「広がる」ように見える現象（q95/q50 比の上昇, ρ=0.620）は、分母である中央値が床（0.02〜0.04）に張り付くための機械的なアーティファクトだった。絶対量で見ると裾のスプレッド q95−q50 は序盤 0.168 → 後半 0.044 へ低下し（ρ=−0.833）、最大値も低下、MAD と中央値は連動して縮む（r=0.979）。**比や歪度のように分母が床に張り付く量を勾配設計の入力に使うと、後半のリスクを過大評価する**。

**(3) z 普遍性は ER-SDE 族内でのみ強く成立**。損傷カーブを z 軸で整列させたときの一致度（RMSE 比、1 未満なら z 整列が有効）:

| 対 | z整列RMSE / step整列RMSE | 判定 |
| --- | ---: | --- |
| ERSDE-Beta ↔ ERSDE-Simple | **0.306** | z 整列で大幅改善（ピークが z ≈ −8.5 に重なる） |
| ERSDE-Beta ↔ Euler-Beta | **1.19** | z 整列でむしろ悪化 |

Euler-Beta の損傷振幅は ER-SDE 系の約 0.42〜0.48 倍しかない。z 軸で勾配を共有する設計は同族内では妥当だが、サンプラーを横断すると振幅スケーリングが別途必要になる。

**(4) 終盤の「仕上げ不足」**。終盤スキップで損傷がわずかに再上昇する現象が実在した（ERSDE-Simple: skip26 の 0.021 → skip30 の 0.046 と約2倍）。ただしスケジューラ依存で、ERSDE-Beta では持ち上がらない（skip30 が全位置の最小 0.012）。ユーザー命名の**「仕上げ不足」**（DiT の最終盤ステップは細部の塗りを精緻化する工程であり、そこを residual 再利用で飛ばすと全体がわずかにぼんやりする。中盤と違い後続ステップによる塗り直しが効かない）が実体である。

重要なのは、**この現象だけは z で説明できない**ことである。Simple の上昇は z ≈ 2.5〜4.5 で起きるが、同じ z 帯の Beta は平坦。Simple のスケジュールは Beta より浅い z（≈ +4.5）で終わって最終歩が大きく、Beta は両端が密で最終歩が小さく z ≈ +7.7 まで到達する。つまり終盤の損傷は「軌道位置」ではなく「最終ステップの歩幅 × 修復時間切れ」で決まる。

これは既存設計の答え合わせにもなった。HareSkip モードの Skip window（既定 0.05〜0.95、進行度 =(step−1)/(n−1) で定義）は 30 ステップ生成で最初と最後の 2 ステップを保護しており、Simple の仕上げ不足は skip29(0.036)・skip30(0.046) に限局し skip28 は床(0.023)。**保護範囲と観測範囲が正確に一致していた**。また、仕上げ不足が z 非整合（スケジュール終端整合）である以上、Skip window を進行度空間で定義したことは正しいドメイン選択だったと確認できた。

### 4.2 ±1ステップアンカー（90枚）

正典: `experiment-HareSkip/analysis-stage2/anchor-analysis/SUMMARY.md`

θ に人間のラベル付けを要しない客観的な物差しを与えるため、画像生成コミュニティで広く知られる経験則「総ステップ数が 1 変わる程度では大した差は生まれない」を利用した。拡張なしで総ステップ数のみ 29 / 31 に変えた画像と 30 ステップ基準画像の差を測り、これを**「ユーザーが日常的に受け入れている揺らぎ」のアンカー**とする（発案はユーザー）。

| 指標 | 値 |
| --- | ---: |
| アンカー分布（LPIPS-VGG）全体 min | 0.018 |
| 中央値 | 0.121 |
| q95 | **0.308** |
| max | 0.368 |

**q95 = 0.308 は、第1段階から独立に導かれた θ 候補 q95 = 0.303 とほぼ一致した**。まったく別の物差し（片や「1ステップ増減の自然な揺らぎ」、片や「単発スキップ損傷分布の 95 パーセンタイル」）が同じ値を指したことは、θ の水準に対する相互裏付けとして意味がある。

アンカー幅はサンプラーに強く依存する（中央値: ERSDE-Beta 0.203 > ERSDE-Simple 0.139 > Euler-Beta 0.079）。したがって判定は必ず**同一条件どうしの対応比較**（その条件のスキップ損傷 vs その条件のアンカー）で行う。

**安全開始位置**（その位置以降の単発損傷がすべて自条件のアンカー内に収まる最初の skip 位置）:

| 基準 | 全体中央値 | ERSDE-Beta | ERSDE-Simple | Euler-Beta |
| --- | ---: | ---: | ---: | ---: |
| anchor_max 基準 | skip **8** | 8 | 7 | 11.5 |
| anchor_min 基準（厳しい） | skip **10** | 9 | 10 | 13 |

どちらの側を基準にするかで約 2 ステップ動くため、**解釈時には必ず基準を明示する**。また Euler-Beta の安全開始位置が遅いのは損傷が大きいからではなく、アンカー（分母）が極端に細いためである。例外 20 件のうち 18 件が Euler-Beta で、超過幅は 0.001〜0.03 程度の僅差にとどまる。絶対損傷で見れば Euler-Beta の後半はむしろ小さい。

### 4.3 第2段階: 加法性の検証（1,260枚）

正典: `experiment-HareSkip/analysis-stage2/additivity/SUMMARY.md`

複数ステップを飛ばしたときの実測損傷と、それぞれを単独で飛ばしたときの損傷の和（以下「単発和」）を比較した。

**(1) 生の残差は 90.6% が負**（実測 < 単発和）。サンプラー別平均残差: ERSDE-Beta −0.161 / ERSDE-Simple −0.131 / Euler-Beta −0.040。一見すると強い劣加法性（足し算より軽い）に見える。

**(2) しかし主因は相互作用ではなく LPIPS の飽和**である。飽和とは、画像が「ほぼ別画像」の水準まで壊れると指標が頭打ちになる性質を指す。単発和のみを入力とする 2 パラメータの頭打ち補正

```text
measured = Lmax · (1 − exp(−predicted / s))
```

を通しただけで、以下の当てはまりが得られた:

| サンプラー | Lmax | s | R²（飽和リンク） | R²（純加法） |
| --- | ---: | ---: | ---: | ---: |
| ERSDE-Beta | 0.580 | 0.505 | **0.847** | −1.929 |
| ERSDE-Simple | 0.785 | 0.835 | **0.921** | −0.828 |
| Euler-Beta | 1.395 | 1.520 | **0.833** | 0.647 |

純加法（実測 = 単発和）では ER-SDE 系で R² が負になるのに対し、同じ入力から飽和リンクは R² 0.83〜0.92 を出す。**残差の大半は相互作用ではなく指標の飽和である**と結論できる。

**(3) 実用域では純加法がそのまま当たる**。単発和がおおむね 0.15 以下（アンカー 1 本ぶん程度）の範囲では、補正なしの足し算がアンカー幅以内で当たる。45/45 条件で合格したパターン: 族C（帯域間遠距離ペア）全 5 パターン、族B のアンカー15系全 4 パターン、族A の (14,15) 以降の隣接ペア全 4 パターン、族B の (4,16)。

**(4) streak（連続スキップ）ペナルティは実在するが微小**。距離を揃えた対比（同じ帯域内で隣接ペアとその近傍の非隣接ペアを比べる）で、飽和補正後の超過分は 3 サンプラーすべてで隣接側が高かった。方向は一貫している。しかし大きさは **+0.009〜+0.030（アンカー幅の 5〜15%）**にとどまる。

同様に、「相互作用が距離とともに指数減衰する」という描像も、飽和を除くとほとんど残らなかった（生残差の距離相関 Pearson 0.555 → 飽和補正後は 0.27 前後）。族C が最も加法的なのは距離が遠いからではなく、損傷振幅が小さくて飽和領域に入らないためである。**純加法性は「距離が遠い」性質ではなく「損傷が小さい」性質**と読むのが正しい。

**(5) negative control が機能**。序盤 5 連続スキップ (2,3,4,5,6) は中央値 LPIPS 0.579 と崩壊レベルに達し（全損傷分布の上位 8%、アンカーの 2.5〜8.1 倍）、「序盤スキップは危険」という主張の実物証拠になった。チェーン (2,3) → (2,3,4,5,6) の単調増加も 45 条件中 33 条件で厳密に成立した。

**(6) 適用限界: danger 帯のカオス**。序盤（danger 帯、z < −4、おおむね step10 まで）では、ペアの損傷が単発の損傷を下回る**非単調な反転**が ER-SDE Beta の 15 条件中 8 条件で発生した（例: schoolgirl-5193 は単発 skip2=0.34 / skip3=0.38 に対しペア (2,3) が 0.15）。単発和がほぼ同じ (2,3) と (3,4) で実測が 3 倍違う例もある。これは飽和（単調圧縮）では説明できず、構図が別の解に切り替わる（basin flip）現象が支配的なカオス領域と考えられる。予測式の適用域は実用域に限るべきである。

### 4.4 第3段階: out-of-sample 検証（450枚）

正典: `experiment-HareSkip/analysis-stage3/verdict/`（`verdict_summary.csv`、`merged_450.csv`、`console_log.txt`）

HareSkip の確率モデルが実際に生成する 10 パターン（aggressiveness a=0.3 / 0.6 / 0.9 で各3つ、＋極端ストレス1つ）を、予測式の較正にまったく使っていない状態で予測し、実測と突き合わせた。予測式は 2 本立て:

- **本命**: 単発和 ＋ 飽和リンク（調整項 2 個: `Lmax`, `s`）
- **対照**: 本命 ＋ streak 項（`S' = Σ単発 + β·Σ_runs(L−1)`、長さ L≧2 の連続ブロックごとに (L−1)β。調整項 3 個）

事前登録した基準に対する判定は次のとおり:

| 基準 | 内容 | 実測値 | 閾値 | 判定 |
| --- | --- | ---: | ---: | --- |
| 1（主基準） | Spearman ρ（パターン1〜9 × 45条件のプール 405点） | **0.930** | ≧0.80 | **合格** |
| 1 | サンプラー別 ρ: ERSDE-Beta / Simple / Euler-Beta | 0.949 / 0.929 / 0.948 | 各 ≧0.70 | **合格** |
| 2 | 実用域（予測≦0.3）の絶対精度: 誤差が条件別 anchor_max 以内の割合（274点中250点） | **91.2%** | ≧80% | **合格** |
| 3（対照） | streak 項によるプール ρ の改善 Δρ | **−0.049** | +0.02未満なら不要 | **streak 項は不要と確定** |

**(1) 順位予測は事前登録基準を明確に上回った**。「29個の単発測定と 28個のペア測定だけから、未見の多点スキップパターンの品質順位を狂いなく予測できる」ことが out-of-sample で実証された。これは第3段階の目的そのもの——列挙不能性（1.55億通り）への回答——の達成である。

**(2) streak 項の不要が確定した**。第2段階の in-sample フィットでは Euler-Beta にのみ R² 改善 +0.046 が見えていたが、out-of-sample では再現せず、しかも符号が反転した（Δρ = −0.014）。in-sample の改善は過学習だったことになる。さらに β の符号がサンプラー間で割れており（ER-SDE 系は負＝連続の方が軽い、Euler-Beta は正＝連続の方が重い）、一貫した物理的意味を持たない項であったことも整合する。

**(3) 絶対値には安全側の系統バイアスがある**。順位は当たるが、実測は予測より一貫して低い。

| 指標 | 値 |
| --- | ---: |
| R²（パターン1〜9、恒等リンク・再フィットなし） | **−1.70** |
| 残差中央値（実測−予測）: ERSDE-Beta / Simple / Euler-Beta | −0.081 / −0.089 / −0.061 |
| MAE: 同上 | 0.088 / 0.100 / 0.096 |
| 低予測域（パターン1・2）の MAE | **0.044 / 0.040** |

実体は「本番の多点スキップ（n_skip 5〜10）では、第2段階（主に 2 点）のフィットより飽和が強く効く」ことである。予測が大きいほど残差も拡大する。低予測域では MAE ≈ 0.04 と実用的な精度が残る。**予測が常に安全側（実測 ≦ 予測）に外れる点は、品質保証の観点ではむしろ都合が良い**——「これくらい壊れるかも」と見積もって実際はそれより軽い、という向きの誤りだからである。

**(4) 極端ストレス（パターン10）は合否から除外**。danger 帯の step3, 5 を手動追加した適用限界の例示である。方向性は的中した（実測中央値 0.389 ＝ パターン1〜9 の中央値 0.139 の 2.8 倍、45 条件すべてで自条件のアンカーを超過）ので negative control として機能する。ただし絶対値は系統的に過大予測（45件中43件で実測<予測）、パターン内の順位相関 ρ=0.40 と弱く、第2段階で見つけた danger 帯の非単調カオスと整合する。

**(5) 外挿は不可**。Euler-Beta で単発和が学習範囲（〜1.111）を超えた 3 点は MAE 0.485（範囲内 0.104 の 4.7 倍）で全点アンカー外だった。n=3 の示唆どまりだが、外挿域では予測式を信用してはならない。

**(6) 指標間整合**。SSIM 11p は符号がすべて期待どおり負（プール −0.892、SSIM は高いほど損傷が小さいため）で、LPIPS-VGG との整合が確認された。

### 4.5 Shift 転移スポットチェック（36枚）

正典: `experiment-HareSkip/analysis-shift-spotcheck/`（`z_mapping_table.csv`、`judgement_table.csv`、`judgement_table_skipaxis.csv`）

HareSkip の中心仮説は「Shift はサンプリングスケジュール（sigma 分布）を歪めるだけで、z → 損傷の写像 `dQ(z)` は不変である」というものである。この仮説は未検証のまま設計の土台になっていたため、反証可能性を担保するスポットチェックを行った。ER SDE-Beta × プロンプト2種（schoolgirl / inkwash）× シード3種の 6 条件で、第1段階カーブの特徴的な 5 点（ピーク skip4 / 肩 skip6 / 致命境界 skip9 / 中盤床 skip17 / 終盤床 skip27）を Shift=1 で再測定した。

**(1) skip ↔ z の対応づけを 3 段で確定**した。patcher / calibration_capture のコード追跡、既存の軌道 CSV の `ER-SDE-Beta-Sft1` 行と実測 `t_now` の 29 点全一致（誤差 ～4e-16）、`LogSnrProxy` 式の再計算検算。

**(2) Δz は全ステップ一様に +2.1972 = 2·ln(3)** だった（`z_mapping_table.csv`）。これは shift 変換の解析的帰結であり、事前試算の「約 −1.1」は符号も大きさも誤り（簡易な線形近似の産物）だったことが判明した。Shift=1 の 5 点はすべて Shift=3 カーブの z 範囲内にあり、外挿は生じていない。

**(3) 中心仮説は素直には成立しない**。z 軸上で Shift=1 の点列は Shift=3 のカーブより**急峻**である:

| 領域 | 点数 | 挙動 | カーブ中央値との比 |
| --- | ---: | --- | --- |
| z < 0（序盤側） | 18 | 16点がカーブ中央値を**上回る** | 1.3〜1.7倍 |
| z > 0（終盤側） | 12 | **全点**が下回る | 0.3〜0.6倍 |

分布帯への収まりは IQR 内が 5/30、q05–q95 内が 10/30（プロンプト対応帯でも 13/30）にとどまる。プロンプト対応帯でも同じ構造が出るため、プロンプト差では説明できない。

**(4) skip 軸（素のステップ位置）でも重ならない**。同じ step なら Shift=1 の方が一様に損傷が小さい（30点中28点が下振れ）。Δz が定数であることから、z 整列は「ステップ整列＋一定の横ずらし」と数学的に等価であり、どちらの座標で見ても重ならない。すなわち**カーブの形（急峻さ）そのものが Shift で変わる**。

**(5) 留意点**: skip27 はカーブ・実測とも損傷が極小（0.006 vs 0.022）で分布帯が細く、外れの解釈は割り引く必要がある。各点 n=6 と標本は小さい。判定は統計検定ではなく系統的なズレの有無を主眼としている。

## 5. 考察

### 5.1 予測式の妥当性と適用限界

第1〜3段階を通して確立されたのは、**「単発損傷の和に頭打ち補正を掛ける」という 2 調整項の予測式が、実運用パターンの品質順位を out-of-sample で言い当てる**という事実である（ρ=0.930）。これは HareSkip の設計思想にとって直接的な意味を持つ。

確率モデル `p_skip(z; a)` が「どのステップを飛ばすか」を決めるとき、その決定の良し悪しを評価するには、任意の skip 集合に対する損傷を見積もれる必要がある。全パターンを列挙して測ることは不可能だが、29 個の単発測定さえあれば、その和と飽和補正で順位が予測できる。**確率勾配の設計は「単発損傷曲線 dQ(z) を入力とする最適化問題」に還元できる**ということである。

ただし適用限界は明確である:

1. **実用域に限る**。単発和が概ね 0.3 を超える領域（＝ danger 帯を複数含むパターン）では、非単調な反転（basin flip 支配）が起きて予測が破綻する。もっとも、そうした領域はどのみち設計上スキップさせないので実害は小さい。
2. **絶対値には安全側バイアスがある**。順位の用途（どのパターンがマシか）には十分だが、絶対値の用途（このパターンは θ を超えるか）では飽和の再較正が必要である。
3. **サンプラー横断には振幅スケーリングが要る**。Euler-Beta の損傷振幅は ER-SDE 系の約半分であり、飽和リンクのパラメータもサンプラー別に較正している（Lmax: 0.58 / 0.78 / 1.40）。z 座標は同族内の位相ずれを吸収するが、振幅は吸収しない。
4. **学習範囲を超えたら信用しない**（外挿域 MAE は範囲内の 4.7 倍）。

### 5.2 調整項を増やさないという設計判断

streak 項を予測式に足さないことは、データが直接支持する結論である。第2段階では実在するが微小（アンカー幅の 5〜15%）、第3段階では out-of-sample で改善がなく（Δρ=−0.049）、in-sample での改善は過学習だったと判明した。

より本質的な論点として、**「予測式を精緻化しても画像は良くならない」**という点がある（2026-07-27 のユーザー所感として記録）。streak 項は予測の精度を上げるだけであるのに対し、ResRefine の後処理改善は損傷そのものを減らす介入であり、そもそも同じ土俵にない。加えて、第2段階で測った streak ペナルティは ResRefine=Reuse に固定した条件での値であり、ResRefine の改良はこのペナルティ自体を縮める方向に働く。つまり**改良すべきなのは予測式ではなく、飛ばしたステップの穴埋め方式**である。

なお、danger 帯を含むかどうかがパターンの成否を決定的に左右することは事実だが、その情報は**単発損傷の値そのものにすでに織り込まれている**（danger 帯の単発損傷は 0.3〜0.6 と大きい）。ゾーンを明示的な調整項として追加する必要はない。

### 5.3 Shift 依存性が設計に与える影響

Shift スポットチェックの結果は、SPEC-alpha に「将来課題」として残されていた「ゾーン境界の shift 別調整」が**実際に必要である**ことを示した。しかも状況は当初の想定より厄介である。

当初想定されていた補正は `delta_z_i`、すなわち z 軸上の平行移動だった。しかし Δz が全ステップ一様に定数（2·ln(3)）である以上、平行移動だけでは「ステップ整列」と等価な補正にしかならず、実測はどちらの座標でも重ならない。**カーブの形が変わるという事実は、単純な平行移動では吸収できない**。

実用方向の読みとしては次のようになる:

- Shift=1 では序盤（danger 側）の損傷が Shift=3 カーブ比で 1.3〜1.7 倍。**低 Shift 運用ほど序盤の保護を強める方向の較正が安全側**である。
- 逆に終盤側（z > 0）では Shift=1 の損傷は 0.3〜0.6 倍と軽い。低 Shift では終盤をもう少し積極的に飛ばせる余地がある。
- ゾーン境界を Shift 依存にする（あるいは確率勾配の傾き `tau_enter` / `tau_exit` を Shift の関数にする）ことが現実的な選択肢になる。

ただし今回測ったのは Shift=1 のみ・ER SDE-Beta のみ・各点 n=6 である。設計に反映する前に水準を増やす必要がある（§7）。

### 5.4 次の有望なレバー: ResRefine 後処理

「予測式の精緻化より後処理の改良に投資すべき」という方向づけの裏取りとして、UjiCache（旧 TeaCache）時代のアーカイブを調査した（2026-07-27 続き5）。

結果は率直に言って**証拠が弱い**。ResRefine の各方式（Reuse / Linear / Taylor2 / EMA）を系統比較した実験データはアーカイブに存在しなかった。唯一の記録は `INTERIM-REPORT_2026-06-15.md` §7 の定性的記述で、そこには確信度「中」と明記されている:「線形外挿は素の residual 流用に負けることも珍しくない」「EMA は最も有望なレバー」「Taylor は未検証」。**枚数も条件も数値も記録されておらず、目視の予備観察が要約されたもの**である。

したがって「EMA が有望」は仮説であって結論ではない。ただし今回の発見と性質が合致する点は指摘できる。終盤の「仕上げ不足」は細部の精緻化が欠落する現象であり、残差を単純に使い回す Reuse では細部の更新が止まってしまう。EMA のように過去の残差を平滑化しながら追従させる方式は、この種の欠落に効く可能性がある。検証は将来課題であり、A/B 比較の設計案は §7 に記す。

## 6. 設計への反映（未実装の提言）

以下はいずれも**提言であり、本レポート時点で実装されていない**。実装はユーザーの裁定を経てから行う。

### 6.1 `sigmoid_band_v0.2` への再較正方針

1. **立ち上がり側（`z_enter` / `tau_enter`）**: ピークが最序盤ではなく skip2〜4（z ≈ −8.5 付近、ER-SDE 系）にあるという実測を反映する。skip1 から単調に減衰させる形ではピーク直前で保護が緩む。danger 帯（z < −4）の保護は現行より強めるのが実測に沿う（第1段階の致命消失境界は θ=q95 基準で skip9、アンカー基準の安全開始位置は skip8〜10）。
2. **立ち下がり側（`z_exit` / `tau_exit`）**: 争点だった taper について、第1段階は「終盤は基本的に安全だが、最終 1〜2 歩だけ仕上げ不足で再上昇する」という構造を示した。しかもこの再上昇は z ではなく進行度（最終歩の歩幅）で決まる。したがって**確率勾配の taper で終盤保護を担わせる現行設計より、進行度空間の Skip window に担わせる方が実測に忠実**である。taper を緩める代わりに Skip window の終端保護を厚くする方向が候補になる。
3. **ゾーン境界 `(low, high)`**: 現行 (−4.0, 0.0)。第1段階の実測ゾーン対応（danger ≈ step10 まで / middle ≈ step11〜22 / safe ≈ step23 以降）と致命消失境界 skip9 は現行境界とおおむね整合する。境界そのものより、境界の **Shift 依存化**が新たな論点である（§5.3）。
4. **max skip streak**: 第2段階・第3段階を通じて streak の効果はアンカー幅の 5〜15% の二次項に過ぎず、予測式には不要と確定した。ただしこれは「予測式に項が要らない」という結論であって「ゾーン別 max streak を撤廃してよい」という結論ではない。max streak は予測ではなく**探索空間を danger 帯から遠ざける制約**として働くため、その役割は別に評価する必要がある。
5. **サンプラー横断**: 単一の確率勾配を全サンプラーで共有すると Euler-Beta には過剰保護になる（振幅が約半分）。サンプラー別の振幅スケーリング係数を持たせるか、Euler-Beta 系を別プリセットにするかは未決。

### 6.2 実装規律

較正パラメータを変更する場合、**`sigmoid_band_v0.1` は書き換えない**（出典: `docs/archive/HANDOFF-next-session.md` §4）。新バージョン `sigmoid_band_v0.2`（または対抗仮説の `monotone_saturate_v0.1`）を `probability_models.py` のレジストリに追加登録し、切り替え可能にする。旧バージョンを残すことで A/B 比較と回帰の検出が可能になる。

ゾーン境界は UI（`hare-zone-boundaries`）から調整できるため、コードを触らずに実機で較正できる。

### 6.3 対抗仮説の扱い

バンド型 `sigmoid_band` に対する対抗仮説として、単調飽和型 `monotone_saturate`（軌道座標に沿って確率が上がり、収束帯以降は max skip streak の強制フル演算以外ほぼすべて飛ばす）が計画に置かれている（`EXPERIMENT-PLAN.md` §1）。今回の実測は、終盤保護を確率勾配の taper ではなく進行度空間の窓に担わせる方が自然だと示唆しており、これは単調飽和型に有利な材料である。ただし A/B 比較の設計（数式・登録・比較手順）は未決のままである。

## 7. 限界と将来課題

1. **絶対値の系統バイアス（飽和の再較正）**。予測式の飽和リンクは第2段階（主に 2 点スキップ）のデータで較正されており、本番の多点スキップ（5〜10 点）では飽和がより強く効く。順位は当たるが絶対値は一貫して過大予測になる（残差中央値 −0.06〜−0.09）。θ 判定のように絶対値が必要な用途では、多点データを含めた再較正が必要である。ただし再較正すれば「安全側に外れる」という現在の性質は失われるため、どちらが望ましいかは用途次第である。

2. **Skip window 比率固定のステップ数依存**。Skip window は比率（既定 0.05〜0.95）で定義されているため、保護されるステップ数が総ステップ数に依存する（20step → 最後の 1 つ、30step → 2 つ）。仕上げ不足が「最終歩の歩幅」で決まるという仮説に立つと、少ステップ生成ほど 1 歩が大きく、保護の必要性はむしろ上がる。**総ステップ数を振った検証**が将来の較正課題である。

3. **ResRefine 方式の比較 A/B**。ResRefine formula（Reuse / Linear / Taylor2 / EMA）の系統比較データは存在せず、「EMA が有望」は目視の予備観察にすぎない。既存設備（Manual Skip 経路、Judge、アンカー）を使って **6条件 × パターン5種 × formula 4種 = 120枚（約2.5時間）**規模の A/B 比較が可能である（2026-07-27 続き5 で記録・未裁定）。第2段階で測った streak ペナルティが ResRefine=Reuse 固定の値である以上、ここは損傷そのものを減らせる唯一のレバーとして優先度が高い。

4. **Shift 水準の追加測定**。今回は Shift=1 のみ、ER SDE-Beta のみ、各点 n=6。カーブの形が Shift で変わるという発見を設計に反映するには、Shift=2 の測定（Δz = 2·ln(1.5) ≈ 0.81 の中間水準）、他サンプラーへの展開、測定点の追加が要る。特に「急峻さの変化」を関数として同定するには 3 水準以上が望ましい。

5. **指標そのものの限界**。LPIPS-VGG は高周波テクスチャの変化に鈍感であり、肉眼の「致命」と乖離しうる。θ の最終選択をユーザーの目視に委ねている理由もそこにある。高周波感度のある指標、またはクロップ拡大目視を 1 軸追加することは計画上の未決事項のままである。

6. **標本サイズと設計の制約**。全段階を通じて 45 条件（サンプラー別 15）であり、分位や裾の指標は各位置で高々 45 点に基づく。z は真の SNR ではなく `LogSnrProxy`（軌道 CSV 由来の代理量）である。skip ↔ 軌道ステップの対応も 2 案（mapA / mapB）の一致で担保した近似である。

7. **θ の目視選択が未完了**。θ 候補 q90=0.221 と q95=0.303 のコンタクトシート比較によるユーザーの最終選択は、まだ行われていない。

## 付録: 用語

| 用語 | 定義 |
| --- | --- |
| 損傷 | スキップあり画像と基準画像の見た目の差を LPIPS で数値化したもの |
| 予測式 | 調整項を削減した計算式。ここでは「単発損傷の和＋飽和リンク」（調整項2個） |
| 飽和 | 画像が「ほぼ別画像」の水準まで壊れると LPIPS が頭打ちになる指標の性質 |
| 飽和リンク | `measured = Lmax·(1−exp(−predicted/s))` という頭打ち補正 |
| 単発和 | 各ステップを単独で飛ばしたときの損傷の合計 |
| アンカー | 拡張なしで総ステップ数のみ 29/31 に変えた画像と 30 ステップ基準の差。「日常的に受け入れられている揺らぎ」の物差し |
| θ | 差異の量が実用上の問題を生まない合格基準（「同じ画像と見做す基準」ではない） |
| 仕上げ不足 | 終盤ステップ（細部の塗りを精緻化する工程）を飛ばすと全体がわずかにぼんやりする現象 |
| streak | 連続するステップをまとめて飛ばすこと。ゾーン別に上限（max skip streak）が設けられている |
| z / LogSnrProxy | 軌道座標 `z = 2·ln((1−t)/t)`。生成が進むほど大きくなる |
| Shift | サンプリングスケジュール（sigma 分布）を歪めるパラメータ。Anima 既定は 3 |
| ResRefine | 飛ばしたステップの残差をどう補うかの方式（Reuse / Linear / Taylor2 / EMA） |
